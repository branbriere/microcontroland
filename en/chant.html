The Song of the Square

Every hour, each region beats the word it wrote: one syllable gives five beats, strike or rest. Six regions, six drums. When all six write the same word, they beat in unison. This page is a transcription: every beat comes from a word published in the day's raw data file.

How the song is transcribed

  1. For each hour, the word of each region is read from the published raw data file (heures[].regions[].mot.syllabes).
  2. Each syllable (0 to 31) is written as 5 bits, most significant first: 1 = strike, 0 = rest. A two-syllable word gives a bar of 10 beats.
  3. Each region has its own sound: Mines low, Fields wood, Refineries metal, Dam deep drum, Harbour shaker, City clap.
  4. A region that is silent that hour does not strike. Nothing is random: the same day always gives the same song.
  5. There is no melody and no pitch: this is the primitive stage. The sound is made by your browser; no audio file is downloaded.

Check: the raw data file of the day, and chant.json (every evening transcribed so far).
